# RTVMandatoryActivity3

Repo for Distributed Systems Mandatory Activity 3

## How to run

- Run the server in a terminal window (from the repo root) with the command "go run /server/server.go"
  - To shut down the server, press CTRL-D or enter "exit" when the server is running
- Run one or multiple clients in separate terminal windows (from the repo root) with the command "go run /client/client.go
  - The client will automatically join the Chit Chat service on startup
  - To write messages, simply write the content of the message in the terminal, and press enter
  - To leave the Chit Chat service, write "leave" as the sole content of a message
